# Image Super-Resolution
Independent locally trained 2×/4× neural restoration. Preview displays an honest missing-weight message. Publication requires a completed model card, genuine evaluation and license review.

Source code is MIT; this does not license training images or future weights. The optional large-data configs use [Kaggle's LSDIR HR subset](https://www.kaggle.com/datasets/parampandya0310/hr-image-denoising-lsdir) plus DIV2K. [Original LSDIR terms](https://ofsoundof.github.io/lsdir-data/) limit the data to academic research, despite the mirror's broader metadata label. Weight/demo rights must be reviewed before publication. Dataset images are not included. Actual checkpoint configuration and completed model cards must identify the corpus and degradation used.
