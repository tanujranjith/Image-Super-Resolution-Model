# Interface assets

`waterfall-preview.png` is an AI-generated illustrative input photograph created with the built-in Image Gen tool for the selected dark workbench design. It is neither training data nor a neural reconstruction. Until genuine exported weights exist, the comparison shows identical input previews on both sides and download stays disabled.

Icons are unmodified Tabler outline icons from https://github.com/tabler/tabler-icons, under `tabler-LICENSE.txt`. Inter is bundled from https://github.com/google/fonts/tree/main/ofl/inter under `Inter-OFL.txt`. All assets are served locally; no font CDN or remote image fetch is needed at runtime.
